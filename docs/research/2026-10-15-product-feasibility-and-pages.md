# 飞牛网盘资源应用：可行性结论与页面设计

日期：2026-10-15。产品暂名：盘栈。本文是产品方案，尚未进入新架构的程序实现。

## 1. 决策结论

**建议做，首版聚焦夸克。技术链路具有明确源码基础，主要工作是能力裁剪、统一与可靠性建设。**

可以建设成一个独立的 x86_64 飞牛原生 FPK：自有 Go 后端、自有前端、自有任务与下载引擎，从参考项目移植所需能力；不依赖 AList、PanSou 或 QAS 服务运行。

目前能确认“源码中存在这些能力”，尚不能确认“目标 NAS 上已复现 AList 速度”或“所有搜索源可长期使用”。首版价值成立的关键是：用户能用更少操作，把一个搜索到的夸克分享可靠下载为 NAS 上的真实文件。

| 维度 | 结论 | 根据与实际影响 |
| --- | --- | --- |
| 分享解析、自动转存 | 有明确基础 | QAS 已实现令牌、分享目录、转存及结果 FID；需移植并补持久化 |
| 原文件下载 | 有明确基础 | AList 已实现直链、匹配请求头、并发 Range；值得提取 |
| 搜索聚合 | 可行，维护持续发生 | PanSou 提供来源适配与解析；具体来源仍需逐个验证 |
| 一个全新程序 | 可行，需要重构边界 | 现有驱动和插件与原项目框架耦合，不能直接拼几个目录就完成 |
| 重启恢复、断点续传 | 工程量较大 | 需要新建转存结果核对、分片落盘和状态恢复机制 |
| x86_64 FPK | 具备实现路径，未设备验证 | Go 可面向 Linux amd64 构建，仍需验证 fnOS 版本、目录权限和生命周期 |
| 与现有 AList 相同速度 | 尚未证实 | 必须同 NAS、同账号、同原文件、相近网络条件对比 |
| 全网全部资源 | 无法保证 | 搜索覆盖取决于可访问来源与分享有效性，不是全量资源数据库 |
| 多网盘统一下载 | 需要逐盘扩展 | 搜到其他盘不等于能转存到夸克；每盘有自己的认证与下载能力 |
| 源码分发 | 按复用代码许可安排 | AList/QAS 为 AGPL，PanSou 为 MIT，PanHub 为非商业许可；保留来源与许可 |

不提供没有实测依据的开发完成百分比、包体积、内存占用、下载速度或交付周期承诺。

## 2. 产品定位与首版范围

一句话定位：**找到资源，选好目录，交给 NAS 下载。**

首版主要服务家庭 NAS 用户，使用一组夸克账号，把搜索或外部分享导入本地目录。默认让普通用户只接触资源、目录、任务；分片大小等技术选项放到高级设置。

首版包含：关键词搜索、直接粘贴分享、分享内容预览、下载整个分享或已指定子目录、NAS 目录选择、转存后下载、任务状态与错误处理、账号连接、目录与来源配置。

后续再扩展：任意文件多选、订阅追更、多账号调度、其他网盘、媒体库刷新、内容整理。首版不把它们做成可点击的承诺。

## 3. 信息架构

一级导航控制为五项：

1. 资源搜索：关键词与分享链接入口。
2. 下载任务：进行中、需要处理、已完成。
3. 网盘账号：首版夸克账号连接与状态。
4. 搜索来源：来源启用、失败状态与重新检测。
5. 设置：下载目录、冲突策略、并发与运行偏好。

资源详情、新建任务、任务详情采用就地弹窗或侧栏，不增加一级导航。首次安装使用独立引导页；完成后落在资源搜索。

推荐“侧栏工作台”布局，便于在搜索与任务之间切换。备选“搜索优先”使用顶部导航和更突出的搜索区域，适合偶尔下载的用户。两者共享功能与状态语义。

## 4. 核心页面

### 资源搜索

- 顶部：页面标题、粘贴链接入口。
- 主要区域：关键词输入、搜索按钮、资源类型筛选、结果列表。
- 每个结果展示：标题、网盘、来源、来源描述；大小与文件数只有解析后可信才展示。
- 主操作“查看资源”，进入内容预览；不把尚未解析的结果标为“有效”。
- 搜索过程逐步追加结果；区分正在搜索、无结果、来源失败和取消。
- 来源失败时保留已有结果，提示部分来源未返回。
- 多网盘搜索后续开放时，未接入下载的盘需明确标识能力，不能出现可直接下载的主按钮。

### 资源详情 / 新建下载

- 展示资源名、网盘、文件与目录清单、提取码状态。
- 首版下载单位为整个分享或分享链接指定的子目录；文件清单用于预览，不画出未实现的任意多选能力。
- 用户选择 NAS 目标目录；另外清楚显示夸克转存位置，避免混淆两种目录。
- 主操作为“转存并下载”；副操作为返回。
- 提交后立刻给任务入口，后台处理不占用搜索页。
- 状态分支：分享失效、提取码不正确、账号未连接、云盘空间不足、NAS 无写权限；分别提供对应操作。
- 默认保留云端转存文件；首版不添加自动删除云端文件开关。

### 下载任务

- 页签：全部、进行中、需要处理、已完成。
- 每项展示：资源名、当前阶段、NAS 保存目录、实际进度和可用操作。
- 阶段使用“排队 → 转存 → 下载 → 校验 → 完成”；转存与下载不能混为一个假百分比。
- 字节进度只在下载阶段给出；速度和剩余时间只有有测量数据时显示。
- 支持查看详情、暂停/继续、取消；已失败任务根据失败阶段提供重试或先更新账号。
- 取消不自动删除已经转存或下载的内容。重试之前先核实既有结果。

### 任务详情

- 第一层：当前阶段、错误或下一步操作。
- 第二层：每个文件的进度、是否校验完成、最终保存位置。
- 第三层：折叠诊断记录；隐藏完整 Cookie、令牌和临时直链。
- 下载完但未完成校验时显示“校验中”，不提前显示“已完成”。
- 部分文件成功时明确列出成功与失败文件，禁止把整个目录默认为全部完成。

### 网盘账号

- 首版只有夸克连接：账号名称、连接状态、重新验证、更新凭据。
- 展示与任务直接相关的过期、空间不足、需要重新登录状态。
- 首版采用凭据配置；源码研究尚未建立可独立使用的扫码登录协议，因此页面不画可用扫码登录按钮。
- 保存后隐藏完整凭据；不把 Cookie、签名或接口参数放进普通任务页面。
- 后续网盘通过该页面扩展，不在首版显示一排“即将支持”的无效按钮。

### 搜索来源

- 显示实际接入来源、启用开关、最近检测结果与错误原因。
- 检测结果有检测时间；不要根据来源包含在上游仓库就显示“在线”。
- 来源故障可以单独停用，不影响其他来源或已经创建的下载。
- TG 作为可选来源；它的网络设置不成为普通搜索的必填项。

### 设置与首次引导

- 安装/首次引导：设置管理密码 → 选择并授权 NAS 下载根目录 → 连接夸克 → 确认搜索来源。
- 引导允许暂时跳过账号连接，先浏览搜索；首次下载时再要求连接。
- 下载位置：授权根目录、默认子目录；真实目录浏览仅在授权范围内。
- 冲突策略：首版默认不覆盖同名内容，并给明确处理入口。
- 下载设置：同时下载任务数、单文件并发、限速；默认保守，不以高并发宣传“解限速”。
- 维护：脱敏诊断与版本信息放次级区域。

## 5. 视觉与交互方向

采用简洁、平面的工具界面：浅色或随系统深色、细分隔线、少量深绿色操作强调、统一 8–12px 圆角。中文正文约 14px，关键输入不低于 16px；路径与数值采用易读等宽字体。内容以列表为主，便于对比来源与任务。

主页面不使用大幅营销海报、假仪表盘或性能评分。资源类型用清晰图标和标签区分。操作状态同时有文字，不只靠颜色。

小窗口下侧栏转成顶部导航；新建下载和任务详情堆叠展示。重要按钮始终有文字，不要求悬停才能出现。支持键盘焦点、Escape 关闭弹窗以及减少动画偏好。

本次交互原型提供两种导航布局，支持切换页面、关键词筛选、查看分享示例、选择保存目录、创建示例任务和查看错误恢复流程。所有内容与进度都标记为演示；不连接真实账户或执行下载。

## 6. 开发前应先通过的三项验证

1. **下载验证**：最小直链 + 会话请求头 + Range 原型在目标 NAS 完成同文件下载与校验，对照现有 AList。若无法复现可接受吞吐，先调整驱动协议而非增加页面。
2. **转存验证**：带提取码、子目录与多文件分享能够转存并取得正确目标 FID；超时恢复不会重复转存。
3. **来源验证**：挑选少量来源，在 NAS 所在网络完成搜索与详情解析；明确错误状态，不能把不可达误报为无资源。

三项通过后再实施完整任务引擎与 FPK；最终需要真实 fnOS 的安装、目录权限、重启恢复和升级验证。

对应源码证据与许可快照见 [能力提取调研](2026-10-15-capability-extraction.md)。
