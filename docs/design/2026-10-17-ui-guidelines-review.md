# 界面稳定性与交互复查

依据 `web-design-guidelines` 技能，本次从官方源读取最新版规则：
https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md

范围：盘栈五个应用页面、管理密码入口、搜索流式更新和任务详情弹窗。保留银白、深灰、蓝色的飞牛桌面应用定位，不使用绿色。

## Findings → fixes

### internal/web/assets/app.js

- `app.js:259` — 下载页原先每秒重建主内容，反复触发入场动画。改为比较响应，仅在数据变化时递增更新原有节点。
- `app.js:25` — 搜索更新替换筛选控件和列表，影响原生下拉菜单与焦点。改为保留控件和结果节点。
- `app.js:164` — 搜索开始后标题缩小、说明隐藏，导致输入框和结果整体上移。统一使用固定的搜索区布局。
- `app.js:177` — 新结果与验证分数自动重排，阅读对象不断换位置。现有资源保持顺序，新资源追加；更改筛选或点击“更新排序”时主动应用最新排名。失效结果继续隐藏。
- `app.js:153` — 主导航缺少可复制的页面入口与跳过导航链接。改用带页面 hash 的链接，保留 Ctrl/Cmd 点击原生行为，并提供跳到主内容入口。
- `app.js:193` — 整个任务列表为 live region，可能每秒重复播报。改为仅播报任务状态数量，速度仍实时显示。
- `app.js:209` — 详情刷新重建弹窗，可能丢失焦点、展开内容、确认勾选和滚动位置。改为原位更新；弹窗由实际标题命名，关闭后返回触发控件。
- `app.js:220` — 提交错误缺少可聚焦的反馈位置。错误区可聚焦并接收服务端错误。
- `app.js:284` — 设置或账号表单可在未保存时直接离开。增加放弃修改确认及浏览器离开提示；返回继续编辑时保留值。
- `app.js:148` — 标志图缺少明确尺寸。补充尺寸，表单补充名称、自动补全、拼写检查与输入提示。
- 页面主标题和内容标题调整为顺序层级，不再从 h1 跳至 h3。

### internal/web/assets/app.css

- `app.css:2` — 网络字体替换及紧缩字距不利于稳定阅读。界面使用系统无衬线字体，统一中英文排版，降低标题字距压缩。
- 原 `panel-arrive` 动画已删除；数据刷新不再产生整体位移或透明度闪动。
- `app.css:32` — 滚动条出现时会改变内容宽度。预留稳定滚动条空间。
- `app.css:44` — 搜索进度和筛选项内容长度变化会改变排布。固定筛选列宽和状态区空间，窄屏使用两列。
- `app.css:61` — 实时速度、剩余时间和耗时原先在 flex 中互相挤动。改为固定网格、等宽数字和独立数值行。
- `app.css:65` — 长来源清单始终参与绘制。为来源行增加 `content-visibility` 与尺寸估计。
- `app.css:66` — 弹窗滚动会向背景传递，关闭按钮点击区域偏小。限制滚动传递，关闭按钮至少 44px，长标题完整换行。
- 底部导航补充安全区域空间；保留可见键盘焦点和减少动画偏好。

### internal/web/assets/index.html

- 增加与浅色、深色界面匹配的主题颜色。
