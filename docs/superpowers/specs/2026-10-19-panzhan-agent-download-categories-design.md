# 盘栈 Agent 下载目录与自动分类设计

日期：2026-10-19

## 目标

Agent 授权复用盘栈「下载位置」已配置的 NAS 下载根目录与默认目录，不让用户在每个授权中重复选择位置。管理员可预先把若干资源类别映射到这些目录内已有的分类目录；Hermes 等 Agent 在预览资源后自动判断类别，盘栈将任务约束到该类别映射的目录。

## 用户流程

1. 用户在盘栈「设置 → 下载位置」设置 NAS 共享根目录和默认目录，并在「Agent 授权」区域为希望启用的类别选择已有子目录。
2. 创建 Agent 授权时只设置名称、有效期和后台下载权限。新的授权继承当时的下载根目录、默认目录和分类映射快照，不显示重复的授权子目录输入框。
3. 用户在 Hermes 搜索并选择候选。Agent 预览实际文件清单；Skill 根据用户明确要求、资源标题和预览文件名，在已配置类别中选择一个类别。
4. 用户明确选择并授权下载后，Agent 提交 `choice_id`、稳定的 `request_id` 和类别 ID。盘栈验证该类别属于本授权，然后使用盘栈保存的映射创建任务目录；Agent 不提交任意文件系统路径。
5. 任务结果包含选择的类别及最终 NAS 目录。Skill 向用户报告该目录和任务状态。无法判断时使用「其他」类别，默认映射到授权的默认目录。

## 类别与映射

首版提供固定类别：电影、电视剧、动漫、音乐、学习资料、软件、其他。管理员可只配置实际需要的类别；没有映射的类别不会提供给 Agent。`other` 始终可用并落到授权的默认目录，作为低置信度分类的安全回退。

分类目录由管理员在 Agent 授权页面用现有 NAS 目录浏览器预先选择，必须已经存在，并且位于盘栈当前「下载位置」根目录和默认目录范围内。每个映射存储相对下载根目录的规范化路径。盘栈不按类别自动创建目录。若所选目录后来被删除或不再可访问，相关下载在创建任务时返回明确错误，不静默改存到其他类别。

新的授权快照保存 `Root`、默认 `Directory` 和已配置类别到目录的映射。之后修改盘栈的默认目录或映射不会扩大或改写已有授权。要应用新配置，用户撤销并重新创建授权。此行为沿用现有 Agent 授权固定下载范围的安全约定。

## 分类责任与安全边界

分类由 Agent 模型根据预览信息完成，盘栈后端不依赖启发式内容识别。分类优先级为：用户对存放位置的明确要求、预览文件清单与资源标题、`other` 回退。Skill 不依据搜索标题单独宣称文件内容已验证；若预览内容与用户选择不符，仍须停止并询问。

MCP 的 `panzhan_preview` 返回本授权实际可用的类别 ID 和显示名称，不向模型暴露根目录之外的路径。`panzhan_download` 接收类别 ID 而非目录字符串。后端只按授权快照解析类别路径，并通过根目录约束验证目标。未知、未配置或路径越界类别拒绝创建任务。原有显式用户确认、幂等请求 ID、Agent 任务隔离和临时故障自动重试均保持不变。

既有授权保留创建时的固定目录，不静默扩大到全局默认目录或新类别。旧 Agent 不传类别时继续使用其既有授权目录，以保持接口兼容；新安装包中的 Skill 必须选择预览返回的类别。

## 界面与配置

- 移除新 Agent 授权表单中的「授权子目录」字段。
- 在同一页面的授权配置区显示分类映射；每类提供目录选择器与当前相对路径，未配置类别可留空，「其他」显示为默认目录回退。
- 创建授权前验证已选目录仍存在且处于当前下载默认目录范围内。
- 已创建授权列表继续显示其实际授权根目录和默认目录，并可显示已固定的分类映射摘要；不显示令牌。
- 分类映射作为全局 Agent 分类设置持久化。修改设置不会回写已创建授权的快照。

## 错误处理

- 当前 NAS 下载目录未设置或不可访问：创建带下载权限的授权时给出设置下载目录的提示；只读授权仍可创建。
- 分类目录不存在、失去授权或离开默认目录范围：保存映射时拒绝；下载时再次验证并返回可读错误。
- Agent 提交未知或未配置类别：不创建任务，提示重新预览可用类别；不默默选择其他路径。
- 分类信息不足：Skill 选择 `other`，说明使用了默认目录；不因此增加额外确认步骤。
- 重试同一个 `request_id`：返回原任务及原类别，不重复创建任务。

## 验证

- Go 测试覆盖授权继承当前根目录和默认目录、分类映射快照、无效/未配置类别拒绝、路径越界拒绝、已删除目标目录的错误、低置信度 `other` 回退、旧授权无类别兼容及 request ID 幂等。
- Node 测试覆盖 Agent 授权 UI 移除重复子目录字段、展示预设类别映射、默认路径和未配置类别状态。
- MCP 工具 schema 和回归测试确认预览仅返回授权类别元数据，下载只接收类别 ID、不接受 agent 提供的路径，并报告最终目录。
- 更新 Hermes Skill、Agent 接入包与 Agent 接入文档，测试 Skill 使用真实预览类别、明确确认和稳定 request ID。
- 运行 `go test ./...`、`go vet ./...`、`node --test scripts/*.test.mjs`、Agent 接入包构建/检查与 FPK 校验。

## 不在范围内

- 自行创建、移动、清理或重命名用户 NAS 目录。
- 读取媒体内容、调用外部分类服务或从搜索标题推断已验证质量。
- 动态修改既有 Agent 授权快照或扩大旧令牌权限。
- 自动完成通知监听器、微信网关配置或额外 Agent 平台集成。
