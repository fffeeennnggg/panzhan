# 搜索资源库与渐进结果实施计划

目标：落实已批准的调研建议和“搜索优先”布局，让盘栈先显示本地已有记录，再并发补充外部结果。

架构：继续使用单个 Go 程序和内嵌网页，不捆绑外部服务。小规模资源库采用有上限的原子 JSON 快照，独立于账号/任务状态；达到更大规模时再迁移数据库。浏览器继续按来源/频道渐进请求，新增独立的本地查询步骤。

- [x] 资源库：新增 internal/search/catalog.go 和测试。按夸克分享 ID + 子目录去重，合并来源，保留提取码、首次发现/最近发现/原始发布时间/检查时间；最多 10000 条，查询最多 500 条。测试重启、同名不同链接、子目录、来源过滤、时间、并发写入和损坏文件保护。
- [x] 搜索调度：调整 internal/search/search.go，成功来源独立缓存，失败来源不污染成功缓存；按来源/频道连续 3 次失败后短暂退避，取消不计故障；公开缓存命中、耗时、恢复时间。测试部分失败和退避恢复。
- [x] API：在 app.New 中加载独立资源库，增加经过现有认证的 /api/search/local；外部结果自动入库，成功解析分享后记录检查时间。资源库写失败仍返回搜索结果并明确告知。测试未登录拒绝、禁用来源、重启可查和校验请求参数。
- [x] 页面：提取 search-results.mjs 模块，合并结构化结果；来源/最近发现时间筛选、相关度/发现时间排序、安全关键词高亮、本地与实时标记。显示检查状态，不把来源记录日期称为资源发布日期。允许搜索中改关键词；旧请求不得污染新搜索，暂停/继续/停止保留结果。
- [ ] 验证与交付：Go 与前端全套测试、语法检查、Windows x86_64 构建和 Linux x86_64 暂存验证已完成；浏览器端搜索、暂停/继续、部分来源错误、分享预览和下载任务流程通过，桌面/移动五页布局无溢出。已更新本机 9867 实例并沿用原数据目录。仍需在 WSL2 网络可用的环境调用官方 fnpack 输出最终 FPK。

边界：资源库为空的首次搜索仍依赖来源可用性；本轮不声称解决所有第三方站点网络问题，不将云搜未公开的后端当成已获得的能力，不自动执行转存或下载真实资源。
