# 飞牛授权下载位置

版本：0.1.4，目标 fnOS x86_64。

盘栈原先只使用包内声明的 `panzhan/downloads` 路径。如今可在“设置 → 下载位置”输入 NAS 共享路径、浏览其子目录并保存为新任务默认位置。提交设置或新建任务时，服务通过 `os.OpenRoot` 检查该路径可读；保存默认目录或创建任务前额外检查目录可写，并立即删除唯一名称的探测文件。

fnOS 仍控制应用进程对共享文件夹的 ACL。若未授权读写，盘栈显示权限错误并拒绝保存；应用不会切换到 root，也不会自行修改 NAS 权限。用户先在飞牛应用设置为盘栈授予目标共享目录读写权限，再输入共享路径。启动参数根路径只是首次安装默认值，保存后的选择持久化到应用状态。

`Settings.DownloadRoot` 是新默认共享根；`Job.DownloadRoot` 保存每个任务创建时的根路径，因此改默认目录不会移动或改变旧任务。旧状态会将空路径迁移到原启动授权根。任务文件仍使用相对目录、`os.Root` 和现有路径校验。

验证包括：Go API 认证测试可保存并浏览第二个授权根；目录写权限探测会清理临时文件；端到端下载 fixture 已将文件写入非默认根并验证路径持久化。Edge 浏览器回归从 `/vol1/媒体库` 浏览到子目录，保存该选择，并确认新任务 API 携带该根路径。完整页面、手机宽度、Go 测试和目录授权拒绝测试均通过。此浏览器使用虚构路径/API fixture；是否可在真实 NAS 写入仍取决于 fnOS 中授予的共享目录权限。
