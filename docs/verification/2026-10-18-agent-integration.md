# 0.2.0 Agent 接入交付验证

版本：0.2.0；目标 fnOS x86_64。功能与配置见 [Agent 接入](../agent-integration.md)。

## 已实现

- 设置页可创建有名称、权限、固定下载目录、到期时间的 Agent 授权，令牌只在创建时展示，状态只保存摘要；可即时撤销。
- 内置 `/mcp` 和 `/api/agent/v1/`，支持同机进程、容器或其他机器上的客户端。Agent 令牌不能作为管理会话使用。
- 搜索、有效性过滤、预览、明确确认后创建后台下载；预览选择限时，创建支持并发重试幂等，授权之间任务与事件隔离。
- 完成/需要处理/取消事件与任务状态一起持久化；重启可补取，确认后不再返回。失败的状态写入会完整回滚新增可选字段。
- Python 标准库监听器在 Agent 主机长轮询，路由来自操作者配置；支持 OpenClaw Hook token 和 Hermes HMAC 直接交付，失败不确认，本地原子记录避免已接受通知在 ACK 丢失后的重复发送。
- 网页中可下载不含凭据的 Agent 接入 ZIP，包含两种客户端配置、Hermes 通知配置、路由模板和操作说明。

## 实际验证

1. `go test ./...` 和改动包 `go vet` 通过。
2. Go 离线端到端测试从搜索、过滤失效候选、预览到确认下载，三个并发重试只创建一个任务且只转存一次，实际文件落盘并比对内容；完成事件重启后仍在，跨授权不可读取/确认。
3. 覆盖缺失用户确认、缺失原会话标识、目录越权参数、选择过期、请求 ID 冲突、权限、到期、撤销、跨站 Origin、管理接口隔离和状态保存失败回滚。
4. 官方 Python MCP SDK **1.30.0** 连接真实构建的隔离盘栈进程，协商 **2025-06-18**，发现 7 个工具，完成任务/事件工具调用，并拒绝未确认的下载。
5. **18 项**前端逻辑测试通过；**4 项** Python 通知测试通过，覆盖 Hermes HMAC、固定接收路由、失败不确认及 ACK 丢失后重启不重发。
6. Playwright/Edge 验证初始化、账号凭据表单、目录选择、搜索与任务流程，以及授权创建、只读下载拒绝、隐藏一次性令牌、撤销后 401。5 个页面在 1024/720/360/320 像素宽度无横向溢出，页面脚本错误为零；审阅了授权页桌面及手机截图。
7. 包结构自测共 **7 项**，Windows 可运行的 4 项通过，依赖 Linux 的 3 项跳过。Agent ZIP 文件清单与公开源码一致，文本换行规范化。
8. 使用官方 fnpack 在既有 WSL Linux 临时目录打包，FPK checksum、Linux ELF 和执行权限检查通过。提取最终 FPK 的程序，与 Linux 构建逐字节一致；在 WSL 临时目录实际启动得到版本 0.2.0、未配置且未登录，SIGTERM 正常停止。归档不含账号、密钥、任务、下载文件或缓存。

## 验证边界

没有配置或操作用户实际 OpenClaw/Hermes 主机，也没有通过真实微信账号发消息。跨网可达性、对应版本 MCP 配置、微信网关登录、用户白名单和实际会话目标需要部署端设置。当前验证证明协议、授权与离线流程，不代表已完成实际微信联调。

`user_confirmed` 是 Agent 对人类已确认的声明，盘栈不会读取微信对话来独立证明；同一授权的 `context` 也是路由别名而非用户身份边界。通知采用至少一次语义，OpenClaw 接受 Hook 不等于微信最终送达；模糊网络失败下还需网关按稳定事件 ID 去重。
