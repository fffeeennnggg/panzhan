# 飞牛首次安装和手机登录修复

版本：0.1.1，目标 fnOS x86_64。

## 修改

- 安装向导新增密码和二次确认字段，最低 8 个、最高 128 个字符。安装回调比较两次输入后，将一次性临时密码写入 `TRIM_PKGVAR` 下权限为 0600 的文件；服务第一次启动时哈希进现有状态模型并删除该文件和旧安装令牌。FPK 不含本机安装数据、密码、Cookie 或任务。
- 管理密码 API 最低要求从 12 字节改为至少 8 个 Unicode 字符，最大 128 字符；本地开发首次设置仍需要一次性令牌，飞牛安装包不再要求寻找 SSH 令牌。
- 为尚未初始化的旧版增加飞牛应用中心配置向导入口；已配置的状态拒绝从该入口重置密码。
- 同源校验规范化 JSON 媒体类型，并兼容外部 Origin 与转发地址相符的 HTTPS 反向代理。对未提供正确代理头、Origin 为 null 等 WebView 请求，页面从 no-store 状态接口取得随机请求令牌并通过自定义头回传；跨域页面无法读取令牌或绕过浏览器预检。错误令牌、未验证的跨站请求、非 JSON 内容仍拒绝。HTTPS 代理下的 Cookie 设置 Secure、HttpOnly、SameSite=Strict。
