# 盘栈 0.2.1 自动重试与打包验证

验证日期：2026-10-19。目标：Linux x86_64 / fnOS 原生 FPK。

## 行为

- 临时网络故障、响应读取中断、超时、限流和服务错误进入任务级自动重试。首次等待 15 秒，指数退避至最多 15 分钟，持续重试。
- CDN 直链失效时重新获取直链，继续原任务；不重复请求已失效直链。
- 重试次数和下次重试时间持久化，重启恢复；升级时恢复已知的旧版临时网络故障任务。
- 暂停、取消停止重试。不确定的转存请求不自动重放；账号、目录权限、文件校验和冲突保留人工处理提示。
- 任务列表、详情和 Agent 状态输出显示重试状态及下次重试时间。

- `go test -p 1 ./... -count=1 -timeout=90s`：通过，包含无用户操作的自动恢复端到端测试。

- Ubuntu WSL `python3 scripts/check_package.py --self-test`：8 项通过，包括 Linux 生命周期检查。
- 官方 fnpack 构建完成；`scripts/check_package.py --fpk` 通过 checksum、ELF amd64、执行权限及包结构校验。包内程序与本次编译结果逐字节一致，包含当前前端和 Agent 接入包。
